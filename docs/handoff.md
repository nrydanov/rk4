# Итоги сессии: методология эксперимента по синхронизации (vdp_sim)

## Контекст

Три осциллятора Ван дер Поля, топология «звезда»: хаб (узел 0) связан с листьями 1 и 2,
прямой связи между листьями нет. Матрица смежности A = [[0,1,1],[1,0,0],[1,0,0]],
степени узлов k₀=2, k₁=k₂=1.

Уравнения: ẋₙ = yₙ; ẏₙ = (μₙ − xₙ²)yₙ − ωₙ²xₙ + εₙsₙ + ηₙcₙ.
Связь инерционная (через x) или диссипативная (через y), каждая — с нормировкой на
степень узла или без. Четыре варианта системы.

Параметры прогона: μ=0.1, ω₀=1, ω₁=1+Δ₁, ω₂=1+Δ₂. Сетка 201×201 по (Δ₁, Δ₂) в
[−0.5, 0.5] с шагом 0.005. ε ∈ {0.01, 0.03, 0.05, 0.07, 0.10}. RK4, dt=0.05,
t_trans=240, T=1600 (окно наблюдения T_obs = 1360). 30 случайных н.у. из [−3,3]⁶
в каждой точке, seed по узлу сетки (одни и те же н.у. для всех ε и всех типов связи —
попарно связанный дизайн). Итого 24 240 600 траекторий.

Признак синхронизации: наклон sᵢⱼ линейной регрессии разности фаз φᵢ−φⱼ по времени;
пара считается запертой при |sᵢⱼ| < θ.

Цель: карты режимов синхронизации, области частичной синхронизации, мультистабильность.

## Главные результаты

### 1. Третий наклон вырожден: режимов 5, а не 8

Из тождества φ₀−φ₁ = (φ₀−φ₂) − (φ₁−φ₂), верного в любой момент, и линейности МНК-оценки
следует **s₀₁ = s₀₂ − s₁₂ точно**. Проверено численно: соотношение выполняется с
машинной точностью (1e-16) на всех 24.2 млн строк.

Следствия:
- Независимых величин две, а не три. Признак строится только по рёбрам звезды (s₀₁, s₀₂).
- Возможных режимов пять: нет / 0↔1 / 0↔2 / 1↔2 / все три. Комбинация «ровно две пары
  из трёх» **динамически невозможна**: из Ω₀₁=0 и Ω₀₂=0 следует Ω₁₂=0.
- Но на карте она встречалась (5083 строки). Причина — **порог**, а не физика:
  точное «равно нулю» сохраняется при вычитании, приближённое «< θ» — нет.
  |s₁₂| ≤ |s₀₁| + |s₀₂| < 2θ, поэтому третий наклон может попасть в [θ, 2θ) и не пройти порог.
- Проверено: 100% фантомных строк имеют встречные знаки s₀₁ и s₀₂, и у 100% из них
  s₁₂/θ ∈ [1.00, 1.99) — ровно как предсказывает неравенство треугольника.
- `std::abs()` в C++ **не виноват** — фантом возникает и со знаковыми наклонами.
  Виноват порог, применённый к трём линейно зависимым величинам.

### 2. Диагональ δ₁=δ₂ — НЕ remote synchronization

На линии δ₁=δ₂ листья идентичны, многообразие x₁=x₂ инвариантно по перестановочной
симметрии. Захват пары 1↔2 там держится **из 100% н.у.** при **незапертом хабе**
(s₀₁≈s₀₂≈0.1–0.4), медиана проскоков 2π ≈ 0.003–0.066. Явление реально и устойчиво.

Но это **не** remote synchronization:
- Ширина по расстройке нулевая (< шага сетки 0.005). Вне диагонали — 3–5 полных
  проскоков 2π за окно, то есть захвата нет.
- Плато отсутствует: s₁₂(δ₂) при фиксированном δ₁ — идеальная буква V без полки.
- corr(s₁₂, |δ₁−δ₂|) = 0.9996, наклон 0.987 → чистая кинематика: листья просто уходят
  от хаба с одинаковой скоростью, когда их расстройки совпали.
- Настоящая ширина полосы (s₁₂ < 1e-4) = ровно диагональ, при **всех** ε.
  А θ-полоса раздувается с 1 до 25 ячеек вслед за θ.

Правильное название: **кластерная синхронизация по симметрии сети / синхронизация
идентичных элементов общим воздействием хаба** (Пекора–Кэрролл). Remote sync
(Nicosia, Gambuzza) требует **неидентичных** периферийных узлов и конечного языка.

Связь с работой научрука: Kuptsov et al., «Radial and circular synchronization clusters
in extended starlike network of van der Pol oscillators», CNSNS 2017 (arXiv:1703.01914) —
там «циркулярные кластеры» живут на лучах длины > 1. Звезда N=3 — вырожденный предел
луча длины 1. Предсказание: удлинить лучи (N=5: хаб + два луча по 2 узла) — и у
циркулярного кластера появится конечная ширина.

### 3. Сдвиг языка захвата на ε/2 у ненормированной связи

Ненормированная связь содержит член −ε·kₙ·xₙ, то есть добавляет пружину,
пропорциональную **степени узла**. Эффективная частота ω²_eff = ωₙ² + ε·kₙ.
У хаба k=2, у листьев k=1 → хаб уезжает по частоте вдвое сильнее. Захват требует
компенсации: (1+δ)² + ε = 1 + 2ε ⟹ **δ ≈ ε/2**.

Подтверждено на данных (Inertial, центр языка 0↔1 по срезу δ₂=−0.40):

| ε | центр языка | ε/2 |
|---|---|---|
| 0.01 | 0.0050 | 0.005 |
| 0.03 | 0.0150 | 0.015 |
| 0.05 | 0.0275 | 0.025 |
| 0.07 | 0.0375 | 0.035 |
| 0.10 | 0.0525 | 0.050 |

У InertialNorm центр = 0 при всех ε.

Это **физическое обоснование нормировки** (не «чтобы топология не влияла на силу связи»,
а «иначе степень узла паразитно сдвигает собственную частоту узла»).

**Следствие**: утверждение «языки в области δ₁=0, δ₂=0» **неверно** для ненормированной
связи — языки вокруг δ = ε/2.

**Второе следствие**: карта несимметрична относительно δ → −δ. Мультистабильность на
диагонали: 16.7% слева-снизу против 34.4% справа-сверху (Inertial, ε=0.10). У нормированной
— 5.2% / 5.2%, симметрия карты 97.9% против 89.6%. Мультистабильные ячейки лежат в
δ ∈ [−0.100, +0.185], середина +0.043 ≈ ε/2. То есть область симметрична — но
относительно **центра языка**, а не начала координат.

### 4. Порог θ = 2π/T_obs ≈ 0.0046

Наклон измеряется в рад/время; за окно наблюдения разность фаз накапливает |s|·T_obs
радиан. Порог выше 2π/T_obs относит к «захвату» траектории, у которых разность фаз
совершает **более одного полного проскока 2π** — что противоречит определению захвата
как ограниченности разности фаз.

Граница зависит **только от длины окна**, не от ε и не от типа связи.

Прежняя таблица порогов (3 яруса по ε × 4 типа связи, значения 0.004…0.10) допускала
до **21.6 проскока** (DissipativeNorm, ε=0.10) и 13 проскоков (Inertial, ε=0.10).
Растить θ вместе с ε было концептуальной ошибкой.

Снизу θ ограничен остаточным наклоном в ядре языка (численный ноль): максимум 0.0025
(худший случай — InertialNorm при ε=0.03), обычно машинный ноль.
Допустимое окно: θ ∈ [0.0025, 0.0046] — множитель 1.9, то есть θ практически
**вычисляется, а не выбирается**.

**Разделитель реального языка от артефакта**: медианное число проскоков 2π среди
«запертых» точек. У реальных рёбер 0↔1, 0↔2 → медиана **0.0** (плато есть).
У пары 1↔2 → медиана **3–5** (плато нет).

⚠️ θ = 2π/T — **не литературный критерий**, вывод собственный. Ссылаться как на стандарт
нельзя. Стандарт (Пиковский, гл. 7–8) — вообще без порога: наблюдаемая частота
Ω = ⟨φ̇⟩, число вращения, **плато** = язык Арнольда.

### 5. Бимодальность распределения наклонов — следствие уравнения Адлера

Уравнение Адлера для разности фаз пары: ψ̇ = Δ − k·sin ψ (Δ — расстройка, k — сила связи).
- |Δ| ≤ k: есть неподвижная точка → захват, Ω ≡ 0 **ровно**.
- |Δ| > k: биения с частотой **Ω = √(Δ² − k²)** (точная формула).

Вблизи границы Ω ≈ √(2k)·√(Δ−k) — корень, бесконечная производная в нуле.
При равномерных расстройках плотность наблюдаемых частот:

p(Ω) = p(Δ)·|dΔ/dΩ| = p(Δ)·Ω/√(Ω²+k²) → **∝ Ω → 0** при Ω → 0.

То есть **незапертая популяция не имеет носителя вблизи нуля**, и провал в распределении
обязан существовать. Бимодальность — не наблюдение, а **предсказание**.

Адлер подтверждён на данных: восстановленная по формуле полуширина языка k стабильна
до трёх знаков (Dissipative, ε=0.01: k = 0.00968, 0.00979, 0.00971, 0.00985, 0.00999
при пяти разных Δ).

**Важно**: старый график KDE строился на **линейной** шкале [0, 0.2] и включал s₁₂.
Запертая популяция целиком живёт в 1e-6…1e-3, то есть в первых полпроцента оси —
и была стёрта сглаживанием. Отсюда старый (неверный) вывод «распределение плоское,
естественного порога нет». На **лог-лог** гистограмме по s₀₁, s₀₂ провал виден чётко,
и 2π/T попадает в него.

Два независимых критерия (физический — менее одного проскока; статистический — провал
между модами) сходятся в одной точке. Это и есть обоснование θ.

### 6. Мультистабильность концентрируется на линии симметрии

При ε=0.05 (Inertial, θ=0.0046): 1.63% карты мультистабильны, но распределены неравномерно:

| доминирующий код | ячеек | мультистабильных |
|---|---|---|
| нет синхр. | 36684 | 0.7% |
| 0↔1 | 1640 | 4.6% |
| 0↔2 | 1637 | 4.2% |
| **1↔2 (диагональ)** | **407** | **54.3%** |
| **полная** | **33** | **78.8%** |

На карте долей захвата видно, что мультистабильные ячейки образуют **когерентную
диагональную полосу**, прорезающую язык, а не рассыпаны по границам.

**Гипотеза (НЕ проверена)**: на δ₁=δ₂ листья идентичны, есть точная перестановочная
симметрия 1↔2 — классический источник сосуществования аттракторов (симметричное
состояние x₁=x₂ и несимметричное). Проверяется бимодальностью |x₁−x₂| по 30 н.у.
в такой ячейке (конечные состояния xf₁, yf₁, xf₂, yf₂ есть в CSV).

## Что осталось сломанным

Из 20 комбинаций (4 связи × 5 ε), по метрике «доля области захвата, меняющая режим
при четырёхкратном сдвиге θ (θ/2 → 2θ)»:

**13 здоровы** — 0.1…2.5%. Карты публикуемы.

**5 упираются в разрешение сетки** — язык захвата у́же шага 0.005:

| комбинация | доля флипов | полуширина языка k |
|---|---|---|
| Inertial, ε=0.01 | 67.1% | 0.0004 (в 12× меньше шага!) |
| InertialNorm, ε=0.01 | 66.8% | 0.0028 |
| Inertial, ε=0.03 | 41.4% | — |
| DissipativeNorm, ε=0.01 | 40.0% | 0.0074 |
| InertialNorm, ε=0.03 | 28.8% | — |

Dissipative при ε=0.01 **здоров** (1.4%), потому что у него k=0.0099 > шага сетки.
То есть дело не в ε, а в отношении ширины языка к шагу сетки.
Карты режимов при ε=0.01 для инерционных связей **измеряют сетку, а не систему**.
Ширину языка при слабой связи надо восстанавливать по Адлеру (k = √(Δ² − Ω²)),
а не считать закрашенные клетки.

**2 упираются в t_trans**:
- Dissipative, ε=0.05 — 9.2% флипов
- DissipativeNorm, ε=0.10 — 5.4%

У Dissipative при ε≥0.05 **половина точек сетки** даёт расходящиеся по н.у. наклоны
(медианный относительный разброс 10–14%), тогда как у всех остальных типов связи он
строго нулевой. Асимптотически так быть не должно — аттрактор один. Значит либо
t_trans=240 мало именно для этой связи, либо там настоящая мультистабильность.
Совпадает с более ранним наблюдением автора: «диссипативная ненормированная при
удвоении t_trans и T меняет класс в 10% случаев, у остальных в 1%».

**θ не является причиной ни в одном из семи проблемных случаев.**

   t_trans = 240 / 480 / 960 на подсетке. Схлопнется ли разброс наклонов по н.у.?
   Если да — t_trans получает обоснование, бимодальность чинится. Если нет — там
   настоящая мультистабильность, и это результат.

   по 30 н.у. в ячейках на диагонали (данные есть: xf₁, yf₁, xf₂, yf₂ в CSV).
3. **Слабая связь**. Либо мелкая сетка (шаг ≲ k/3 ≈ 1.5e-4 для Inertial при ε=0.01),

   циркулярного кластера конечная ширина. Прямое продолжение работы Купцова 2017.
