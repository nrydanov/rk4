## Правила работы
1. При работе с табличными данными всегда используй Pandas для ускорения анализа, старайся организовывать агрегацию эффективно
2. Всегда предоставляй эмпирические доказательства гипотез, основываясь на имеющихся данных
3. Всегда резко поправлял меня, если я неточен в терминологии. Соответствие терминологии проверяй по литературе из источников в sources. Кэшируй выдержки из книг в sources/brief.md, чтобы не парсить повторно.
4. Никогда не ставь знаки ударения в русских словах — ни комбинирующим символом (у́же), ни командой LaTeX (временн\'ая). Комбинирующий акцент разрывает UTF-8 и ломает сборку pdflatex. Если без ударения фраза двусмысленна — перепиши фразу.
5. В русском тексте употребляй только общепринятые в русскоязычной литературе по нелинейной динамике термины. Не изобретай кальки с английского: не «запертая мода», а «мода захвата»; не «сплэй-состояние», а «состояние с равномерно распределёнными по окружности фазами». Если для понятия нет устоявшегося русского термина — опиши его явно, а не транслитерируй. Прежде чем ввести новый термин в текст, дай ему определение; безопределённых ярлыков быть не должно.
